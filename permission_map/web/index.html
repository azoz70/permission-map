About PERMISSION MAP
Local-first access analysis for imported system exports. It helps identify who has access to what and how access was granted.
  1. Export users, roles, resources, permissions and relationships.
  2. Choose each file type and import it in dependency order.
  3. Review the live dashboard.
  4. Use the existing CLI map/analyze commands for deeper analysis.
  5. Reconcile HR accounts and record decisions in a review campaign.
This interface does not revoke access. Findings are review candidates, not automatic policy violations. Keep the service on localhost.
