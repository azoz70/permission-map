About PERMISSION MAP

PERMISSION MAP helps security and IAM teams answer: who has access to what, why, and should they retain it? The intended workflow uses exported access lists without connecting directly to corporate systems.

  1. Export the HR employee master.
  2. Export user, role and permission lists from each system.
  3. Import and validate files using the CLI (web import is not enabled yet).
  4. Match identities and examine effective access.
  5. Flag privileged, unmatched and departed-user access for review.
  6. Ask system owners to approve, remove or investigate access.
  7. Re-import updated exports to verify remediation and produce reports.
This initial web integration is read-only. Analysis quality depends on the completeness of imported data. It cannot directly revoke access.
